# Automações N8N

Repositório com automações desenvolvidas na plataforma [N8N](https://n8n.io/), aplicando lógica de fluxo visual (no-code/low-code) para otimização de processos repetitivos, integrando APIs, webhooks e agentes de IA.

## Sobre

Cada pasta deste repositório representa um projeto de automação, com:
- Descrição do problema resolvido e do fluxo da solução
- Print do workflow visual
- Arquivo workflow.json (exportado do N8N, pode ser importado por qualquer instância N8N para reproduzir o fluxo)
